# 🌿 EcoBazar

EcoBazar — это современное веб-приложение для онлайн-торговли экологически чистыми продуктами. Проект предоставляет удобный интерфейс для просмотра товаров, управления корзиной и оформления заказов.

## 🚀 Технологический стек

- **Языки:** TypeScript, JavaScript, HTML, SASS (SCSS)
- **Фреймворки:** Nuxt.js (Vue 3), Vue Router
- **Серверная часть:** Nitro (встроенный сервер Nuxt)
- **Стилизация:** SASS с модульной структурой (partials)
- **Инструменты:** Nuxt CLI, npm

## 📦 Установка и запуск

### Требования

- Node.js (версия 18 или выше)
- npm (версия 9 или выше)

### Установка

```bash
# Клонирование репозитория
git clone https://github.com/your-username/ecobazar.git
cd ecobazar

# Установка зависимостей
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:3000`

### Сборка для продакшена

```bash
# Создание production-сборки
npm run build

# Предпросмотр production-сборки
npm run preview
```

## 💡 Примеры использования

### Основные команды

```bash
# Запуск в режиме разработки с горячей перезагрузкой
npm run dev

# Проверка типов TypeScript
npx nuxt typecheck

# Генерация статического сайта
npm run generate
```

### Структура страниц

- **Главная страница** (`/`) — каталог товаров и основные категории
- **Страницы товаров** — детальная информация о продуктах
- **Корзина** — управление выбранными товарами
